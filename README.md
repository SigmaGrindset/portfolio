# Portfolio — Antonio Batarilović

## Stack
- Vite + React 18 + TypeScript
- TanStack Router (file-based)
- Tailwind CSS v4 (`@theme`)
- i18n (custom, HR/EN)
- lucide-react

## Razvoj
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```

## Deploy
Push na GitHub i poveži s Vercelom — automatski detektira Vite.
